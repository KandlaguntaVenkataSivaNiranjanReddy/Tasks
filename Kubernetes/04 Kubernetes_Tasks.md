## Task 31: Verifying Existing Namespace for ReplicaSet Deployment

## Task 32: Creating ReplicaSet YAML Using matchLabels

### Objective

Create a ReplicaSet configuration file using matchLabels selector.

### Requirements

- Create a file named rs.yaml
- Add apiVersion: apps/v1 in YAML file
- Add kind: ReplicaSet in YAML file
- Add metadata configuration with ReplicaSet name javawebapprs
- Add namespace configuration as test-ns
- Configure replicas value as 2
- Add selector configuration using matchLabels
- Add selector label app: javawebapp
- Add Pod template metadata labels app: javawebapp
- Add container image configuration
- Add containerPort configuration
- Save YAML file
- Verify ReplicaSet YAML content

---
