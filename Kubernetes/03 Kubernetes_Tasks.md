# Kubernetes ReplicationController Practical Lab Tasks

## Task 21: Creating Namespace for RC Testing

### Objective

Prepare a namespace for ReplicationController deployment.

### Requirements

- Create a namespace named test-ns
- Verify namespace creation
- Display available namespaces
- Confirm namespace readiness for RC deployment

---

## Task 22: Creating ReplicationController YAML

### Objective

Create a ReplicationController configuration file.

### Requirements

- Create a file named rc.yaml
- Add apiVersion: v1 in YAML file
- Add kind: ReplicationController in YAML file
- Add metadata configuration with RC name javawebapprc
- Add namespace configuration as test-ns
- Configure replicas value as 2
- Add selector configuration app: javawebapp
- Add Pod template metadata labels app: javawebapp
- Add container image configuration
- Add container port configuration
- Save YAML file
- Verify ReplicationController YAML content

---

## Task 23: Deploying ReplicationController

### Objective

Create ReplicationController and deploy Pods.

### Requirements

- Apply rc.yaml file using kubectl
- Verify ReplicationController creation
- Display available ReplicationControllers
- Verify desired replica count
- Verify current replica count
- Confirm successful RC deployment

## Task 30: Deleting RC and Verifying Cleanup / Orphan Behavior

### Objective

Understand ReplicationController deletion behavior.

### Requirements

- Recreate ReplicationController if required
- Verify running Pods under RC
- Delete ReplicationController normally
- Verify RC deletion
- Verify Pods are deleted automatically
- Recreate ReplicationController again
- Delete RC using --cascade=orphan option
- Verify Pods remain running without controller
- Confirm RC deletion behavior understanding
