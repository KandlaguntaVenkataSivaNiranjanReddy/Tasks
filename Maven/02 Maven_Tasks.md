## Task 11: Exploring Maven Project Structure

### Objective

Verify the basic structure of a Maven project.

### Requirements

- Clone a Maven project from GitHub  
- Navigate to the project directory  
- Display available project files  
- Verify the src directory  
- Verify the pom.xml file  
- Confirm the Maven project structure
