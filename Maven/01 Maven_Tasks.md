# Maven  Tasks

---

## Task 1: Installing Java for Maven

### Objective

Install Java as a prerequisite for Maven setup.

### Requirements

- Launch a Linux server instance  
- Connect to the server using SSH  
- Switch to root user  
- Update system packages  
- Install Java JDK  
- Verify Java installation using version command  

---

## Task 2: Installing Required Utilities

### Objective

Install required tools needed for Maven installation.

### Requirements

- Verify current system packages  
- Install wget utility  
- Install unzip utility  
- Verify whether both utilities are installed successfully  

---

## Task 3: Downloading Maven Package

### Objective

Download Maven package from the official Apache source.

### Requirements

- Navigate to the /opt directory  
- Open the Apache Maven official download page  
- Copy the latest Maven package URL  
- Download the Maven package using wget  
- Verify whether the package is downloaded successfully  

---

## Task 4: Extracting Maven Package

### Objective

Extract the downloaded Maven package.

### Requirements

- Verify the downloaded Maven zip file  
- Extract the Maven package  
- Verify the extracted Maven directory  
- Display available files after extraction  

---

## Task 5: Configuring Maven Environment Variables

### Objective

Configure system environment variables for Maven.

### Requirements

- Open .bash_profile file  
- Configure M2_HOME variable  
- Update PATH variable for Maven  
- Save the configuration changes  
- Exit the configuration file  

---

## Task 6: Reloading Environment Configuration

### Objective

Apply Maven environment variable changes.

### Requirements

- Reload .bash_profile configuration  
- Verify whether environment variables are loaded successfully  
- Check Maven version using command line  

---

## Task 7: Verifying Maven Installation

### Objective

Confirm successful Maven installation.

### Requirements

- Execute Maven version command  
- Verify installed Maven version  
- Verify installed Java version  
- Confirm Maven installation success  

---

## Task 8: Exploring Maven Directory Structure

### Objective

Inspect Maven installation directories.

### Requirements

- Navigate to Maven installation directory  
- View bin directory contents  
- View boot directory contents  
- View lib directory contents  
- View conf directory contents  
- Verify Maven executable files  

---

## Task 9: Working with Maven Configuration File

### Objective

Inspect Maven global configuration settings.

### Requirements

- Navigate to Maven conf directory  
- Locate settings.xml file  
- Open the configuration file  
- Verify proxy configuration section  
- Verify repository configuration section  
- Verify server credential section  

---

## Task 10: Understanding Maven Artifact Types

### Objective

Verify different Maven build artifact types.

### Requirements

- Create sample Java project examples  
- Identify JAR application structure  
- Identify WAR application structure  
- Identify EAR application structure  
- Verify differences between JAR, WAR, and EAR packaging types
