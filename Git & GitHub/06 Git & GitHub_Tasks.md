# Git & GitHub Tasks

---

## Task 51: Committing Only Completed Code

### Objective

Commit only completed and tested code changes.

### Requirements

- Modify one or more project files for development changes  
- Verify the modified files using Git status  
- Complete the pending code changes  
- Test the modified code before committing  
- Stage the modified files  
- Commit the changes with a proper commit message  
- Verify the commit history  

---

## Task 52: Writing Proper Commit Messages

### Objective

Create meaningful commit messages for project changes.

### Requirements

- Modify one or more project files for development changes  
- Stage the modified files  
- Commit changes using an unclear commit message  
- Review the commit history  
- Update the previous commit message using amend command  
- Verify the updated commit message  

---

## Task 53: Working with Feature Branch Workflow

### Objective

Perform development work using feature branches instead of main branch.

### Requirements

- Verify the currently active branch  
- Create a new feature branch  
- Switch to the feature branch  
- Modify one or more project files for development changes  
- Stage all modified files for commit  
- Commit the changes with a meaningful commit message  
- Verify branch-specific commit history  

---

## Task 54: Creating Pull Request Workflow

### Objective

Push feature branch changes and simulate pull request workflow.

### Requirements

- Push feature branch changes to GitHub  
- Open GitHub repository  
- Create a new pull request  
- Compare feature branch with main branch  
- Add pull request title and description  
- Create the pull request  
- Verify pull request creation  

---

## Task 55: Managing Git Stash Cleanup

### Objective

Manage and clean unused stash entries.

### Requirements

- Modify one or more project files for development changes  
- Save changes using Git stash  
- Display available stash entries  
- Apply a stash entry  
- Delete a specific stash entry  
- Verify updated stash list  
- Clear all remaining stash entries  

---

## Task 56: Cloning Remote Repository

### Objective

Create a local copy of an existing remote repository.

### Requirements

- Copy the GitHub repository URL  
- Clone the repository into local system  
- Verify downloaded project files  
- Verify hidden .git folder  
- Check remote configuration  
- Verify default remote alias name  

---

## Task 57: Performing Fast Forward Merge

### Objective

Merge branch changes using fast-forward strategy.

### Requirements

- Create a bugfix branch from main branch  
- Add multiple commits in bugfix branch  
- Verify bugfix branch commit history  
- Switch back to main branch  
- Merge bugfix branch into main branch  
- Verify fast-forward merge result  
- Check the updated commit history after merge completion  

---

## Task 58: Performing Three-Way Merge

### Objective

Merge branches when both branches have independent commits.

### Requirements

- Create a hotfix branch from main branch  
- Add multiple commits in the hotfix branch  
- Add separate commits in the main branch  
- Attempt to merge hotfix branch into main branch  
- Enter merge commit message  
- Complete the merge process  
- Verify the merge history using Git log commands  

---

## Task 59: Cherry-Picking Specific Commits

### Objective

Merge only selected commits from another branch.

### Requirements

- Create a feature branch  
- Add multiple commits in feature branch  
- View the commit history of the feature branch  
- Identify a specific commit for cherry-pick  
- Switch to main branch  
- Cherry-pick the selected commit  
- Verify whether only selected commit is merged  

---

## Task 60: Comparing Git Fetch and Git Pull

### Objective

Retrieve remote changes using fetch and pull operations.

### Requirements

- Verify current project files  
- Fetch latest changes from remote repository  
- Verify that working directory remains unchanged  
- Merge fetched changes manually  
- Verify the updated project files after merge operation  
- Pull latest changes directly from remote repository  
- Verify automatic updates in working directory
