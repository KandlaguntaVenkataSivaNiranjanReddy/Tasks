# GitHub Lab - Tasks

---

## Task 1: Install Git Application

### Objective

Learn how to install Git before starting version control work.

### Requirements

- Check whether Git is already installed  
- Download Git from official website  
- Install Git application  
- Complete installation setup  
- Open Git Bash  
- Verify Git installation using version command  

---

## Task 2: Create GitHub Account

### Objective

Create a GitHub account for project collaboration.

### Requirements

- Open GitHub website  
- Click signup  
- Enter email address  
- Create username  
- Create password  
- Verify email account  
- Login successfully  

---

## Task 3: Explore GitHub Dashboard

### Objective

Understand the GitHub dashboard interface.

### Requirements

- Login to GitHub  
- Explore profile section  
- Explore repositories section  
- Explore organizations section  
- Explore settings section  
- Understand dashboard navigation  

---

## Task 4: Create GitHub Organization

### Objective

Understand how companies manage teams using GitHub organizations.

### Requirements

- Open GitHub dashboard  
- Navigate to organizations  
- Create a new organization  
- Choose free plan  
- Configure organization details  
- Verify organization creation  

---

## Task 5: Create Teams in Organization

### Objective

Learn how companies separate teams inside GitHub organizations.

### Requirements

- Open organization dashboard  
- Navigate to teams section  
- Create development team  
- Create testing team  
- Create operations team  
- Verify team creation

### Objective
