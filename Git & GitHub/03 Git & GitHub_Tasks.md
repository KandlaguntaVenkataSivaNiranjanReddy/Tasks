# Git & GitHub Tasks

---

## Task 21: Working with Remote Repositories

### Objective

Understand how to connect local Git with GitHub.

### Requirements

- Create a repository in GitHub  
- Copy the repository URL  
- Add the remote repository locally  
- Use a custom alias name instead of origin  
- Verify remote connection details  
- Understand remote alias usage  

---

## Task 22: Pushing Local Code to GitHub

### Objective

Learn how to upload local project code to GitHub.

### Requirements

- Commit project files locally  
- Push code to GitHub repository  
- Handle GitHub authentication properly  
- Understand Personal Access Token usage  
- Verify uploaded files in GitHub  
- Confirm successful push operation  

---

## Task 23: Reusing Existing GitHub Repository

### Objective

Understand how multiple local folders can connect to the same GitHub repository.

### Requirements

- Create a second project folder  
- Initialize Git inside the new folder  
- Connect to an existing GitHub repository  
- Verify remote configuration  
- Create new files in the second folder  
- Commit and push new files  
- Verify updates in GitHub  

---

## Task 24: Pulling Latest Changes Before Push

### Objective

Learn why pulling latest code is important in team environments.

### Requirements

- Modify files locally  
- Attempt to push changes  
- Observe push rejection error  
- Pull latest changes from GitHub  
- Resolve synchronization issues  
- Push changes successfully after pull  
- Verify latest files locally and remotely  

---

## Task 25: Understanding Git Revert

### Objective

Learn how to safely undo bad commits without deleting history.

### Requirements

- Modify existing files  
- Create new files  
- Commit the changes  
- Identify incorrect commit from Git history  
- Revert the bad commit  
- Verify restored file state  
- Push reverted changes to GitHub  
- Confirm reverted content in GitHub repository  

---

## Task 26: Using .gitignore for Sensitive Files

### Objective

Learn how to prevent private files from being pushed to GitHub.

### Requirements

- Create sensitive files like passwords or secrets  
- Create a .gitignore file  
- Add ignored filenames inside .gitignore  
- Attempt to stage all files  
- Verify ignored files are excluded  
- Commit .gitignore configuration  
- Push changes to GitHub safely
