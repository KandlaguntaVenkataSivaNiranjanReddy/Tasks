# Git & GitHub  Tasks

---

## Task 11: Understanding Git Initialization

### Objective
Learn how to create a project folder and initialize Git tracking.

### Requirements

- Create a new folder for the project  
- Open Git Bash inside the folder  
- Initialize Git using Git commands  
- Verify that the hidden .git directory is created  
- Check the current repository status  

---

## Task 12: Creating Files and Understanding Working Area

### Objective
Understand how newly created files appear inside the Git working directory.

### Requirements

- Create multiple files with different extensions such as .java, .py, .sh, and .txt files  
- Create both normal files and hidden files  
- Verify created files using Linux commands  
- Check Git status after creating files  
- Identify which files are tracked and untracked  
- Understand why files appear in red color  

---

## Task 13: Moving Files to the Staging Area

### Objective
Learn how files move from Working Area to Staging Area.

### Requirements

- Add a single file to staging  
- Verify staging using Git status  
- Add only .java files to staging  
- Add all files to staging  
- Observe color changes in Git status  
- Identify staged and unstaged files properly  

---

## Task 14: Understanding git add . vs git add *

### Objective
Learn the difference between adding normal files and hidden files.

### Requirements

- Create normal files and hidden files  
- Use git add * and observe which files move to staging  
- Verify whether hidden files are staged or not  
- Reset staging changes  
- Use git add .  
- Verify that hidden files are now added to staging  
- Compare the behavior of both commands
