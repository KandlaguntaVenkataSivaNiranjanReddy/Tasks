# Git & GitHub Tasks

---

## Task 41: Creating Your First Git Tag

### Objective

Create a version tag for a stable project release.

### Requirements

- Verify the currently active branch before creating a tag  
- Check project files and confirm that the code is stable  
- Create a new lightweight tag named v1.0.0  
- Display all available Git tags in the repository  
- Verify whether the tag is successfully created  

---

## Task 42: Creating Annotated Tags

### Objective

Create annotated tags with release messages.

### Requirements

- Create an annotated tag named v1.0.1  
- Add a release message while creating the tag  
- Display all available Git tags in the repository  
- Verify whether the annotated tag is successfully created  
- View detailed tag information using Git commands  

---

## Task 43: Viewing Tag Information

### Objective

Inspect detailed information about created tags.

### Requirements

- Display all available Git tags in the repository  
- Select a specific tag for inspection  
- View complete details of the selected tag  
- Verify the message associated with the selected tag  
- Verify the commit information linked to the selected tag  

---

## Task 44: Deleting Local Tags

### Objective

Delete unnecessary tags from the local repository.

### Requirements

- Create multiple sample tags for practice  
- Display all available Git tags in the repository  
- Delete a specific local tag  
- Verify whether the selected tag is removed successfully  
- Confirm the remaining available tags in the repository

## Task 45: Pushing Tags to GitHub

### Objective

Push release tags from local repository to GitHub.

### Requirements

- Verify the remote repository connection  
- Push a single tag to the GitHub repository  
- Verify the tag availability in the GitHub repository  
- Push all available tags to GitHub  
- Confirm all tags are successfully available in the remote repository

## Task 46: Deleting Remote Tags

### Objective

Remove unnecessary tags from GitHub.

### Requirements

- Display all available remote tags  
- Select a remote tag for deletion  
- Delete the selected tag from the GitHub repository  
- Verify whether the tag is removed from the GitHub repository  
- Confirm the remaining remote tags available in the repository

## Task 47: Creating Releases Using GitHub UI

### Objective

Create release versions directly from GitHub.

### Requirements

- Open the GitHub repository  
- Navigate to the Releases section in GitHub  
- Create a new release  
- Add a new tag name for the release  
- Select the appropriate commit reference  
- Add a release title and description  
- Publish the release in the GitHub repository  
- Verify whether the release is successfully created  

---

## Task 48: Saving Work Using Git Stash

### Objective

Temporarily save unfinished work without committing changes.

### Requirements

- Modify one or more project files  
- Verify modified files using the Git status command  
- Save the changes using Git stash  
- Add a custom stash message while saving the changes  
- Verify that the working directory becomes clean  
- Display all available stash entries in the repository  

---

## Task 49: Applying and Managing Stash Changes

### Objective

Restore stashed work and manage stash entries.

### Requirements

- Display all available stash entries  
- Apply a specific stash entry  
- Verify the restored file changes  
- Commit the restored changes with a proper commit message  
- Delete a specific stash entry  
- Verify the updated stash list  
- Clear all remaining stash entries from the repository  

---

## Task 50: Restoring File Changes

### Objective

Discard unwanted local file changes using Git restore.

### Requirements

- Modify a project file  
- Verify the modified file content  
- Check the current Git working directory status  
- Restore the modified file using Git restore  
- Verify whether the original file content is restored  
- Confirm that the working directory status is clean
