# Git & GitHub Tasks

---

## Task 31: Creating Your First Branch

### Objective

Create a new branch from the main branch for development work.

### Requirements

- Check the currently active branch  
- Display all available local branches  
- Create a new branch named development  
- Verify whether the development branch is successfully created  

---

## Task 32: Switching Between Branches

### Objective

Switch between different branches to work on separate versions of the project.

### Requirements

- Switch to the development branch using the checkout command  
- Verify the currently active branch  
- Switch back to the main branch using the checkout command  
- Verify the currently active branch  
- Switch again to the development branch using the switch command  
- Verify the currently active branch after switching  

---

## Task 33: Create and Switch Branch in Single Command

### Objective

Create a new branch and switch to it using a single Git command.

### Requirements

- Create and switch to a new feature branch using the checkout -b command  
- Verify the currently active branch  
- Switch back to the development branch  
- Create and switch to another feature branch using the switch -c command  
- Verify the currently active branch after creation  

---

## Task 34: Renaming Branches

### Objective

Rename incorrectly created branches with proper naming conventions.

### Requirements

- Create a branch with an incorrect branch name  
- Rename the incorrectly created branch  
- Verify the updated branch name  
- Switch to the renamed branch  
- Display the branch list to confirm the updated branch name  

---

## Task 35: Deleting Branches

### Objective

Delete unused branches after completing development work.

### Requirements

- Create temporary branches for testing deletion operations  
- Delete a merged branch using the safe delete option  
- Verify whether the branch is deleted successfully  
- Attempt to delete an unmerged branch  
- Force delete the unmerged branch  
- Verify the remaining available branches  

---

## Task 36: Working in Development Branch

### Objective

Perform file modifications and commits inside the development branch.

### Requirements

- Switch to the development branch  
- Modify one or more project files  
- Check file changes using the diff command  
- Stage the modified files  
- Commit the staged changes with a proper commit message  
- Verify the commit history  

---

## Task 37: Merging Development Branch to Main

### Objective

Merge completed development changes into the main branch.

### Requirements

- Switch to the main branch  
- Verify the existing project files before merging  
- Merge the development branch into the main branch  
- Verify the merged files after completing the merge  
- Check the commit history after merging  

---

## Task 38: Handling Uncommitted Changes

### Objective

Handle uncommitted changes while switching between branches.

### Requirements

- Switch to the development branch  
- Modify a file without committing the changes  
- Check the current Git status  
- Switch to the main branch  
- Verify whether the uncommitted changes are carried to the new branch  
- Return to the development branch  
- Stage and commit the changes properly  

---

## Task 39: Resolving Merge Conflicts

### Objective

Resolve merge conflicts when multiple branches modify the same file.

### Requirements

- Create a new feature branch from the development branch  
- Modify the same file in the development branch  
- Commit the changes in the development branch  
- Switch to the feature branch and modify the same file  
- Commit the changes in the feature branch  
- Merge the feature branch into the development branch  
- Identify the merge conflict generated by Git  
- Resolve the conflict manually by editing the file  
- Commit the resolved changes  
- Verify the final file content after conflict resolution  

---

## Task 40: Managing Remote Branches

### Objective

Manage both local and remote branches using GitHub.

### Requirements

- Display all local branches  
- Display all remote branches  
- Push a local branch to the GitHub remote repository  
- Verify whether the remote branch is created successfully  
- Create a new branch directly from the GitHub web interface  
- Fetch the latest remote branch information  
- Create a local tracking branch for the remote branch  
- Verify synchronization between local and remote branches
